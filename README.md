## Sobre este repositorio

Este repositorio contiene la web pública de presentación y sirve como punto de entrada a mis proyectos. El sitio está construido desde cero con HTML, CSS y JavaScript vanilla, sin frameworks de frontend ni proceso de build.

El portfolio publicado contiene la información completa de cada proyecto. Este README se limita a documentar el repositorio y enlazar el trabajo relevante, evitando duplicar su contenido.

## Stack

- HTML5 semántico.
- CSS3 con variables, Grid, Flexbox y diseño responsive.
- JavaScript vanilla para la navegación y las animaciones.
- `IntersectionObserver` para las animaciones de entrada.
- Google Fonts: DM Sans y Space Grotesk.
